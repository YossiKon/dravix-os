# Changelog

## 2.0.0

A new add-on for Dravix 2.0. The robot now talks to Home Assistant by itself, so the add-on is just
one simple page in the sidebar:

- the robot's state, battery and firmware at a glance
- Mode (Normal, Busy, Sleep) and Private mode
- choose every tile and the air conditioner from a list
- start any game, make a face
- install the voice commands and the photo automation with one tap

It replaces the old companion service (versions 0.1.x) and its dashboard.
